# Security Policy

## Supported Versions
This repository contains only documentation and the static site scaffold. There is no product code in scope for this repository.

## Reporting a Vulnerability

- **Factual Errors / Documentation Issues**: Please report these via GitHub Issues or contact our team email.
- **Product Security Vulnerabilities**: If you discover a security issue in the Void Vault tool itself, please contact the team privately at [team email]. Do not open a public issue.
